# Автодеплой islamtarih.ru

После push или мержа в main GitHub Actions проверяет TypeScript, собирает статический сайт в out/ и загружает его на Timeweb. Ручной повторный запуск: Actions → Deploy to Timeweb → Run workflow (main).

В Settings → Secrets and variables → Actions → New repository secret добавьте:

| Secret | Значение |
| --- | --- |
| FTP_USER | Логин отдельного пользователя для деплоя, например ct290930_deploy |
| FTP_PASSWORD | Пароль этого пользователя, не пароль основного аккаунта |
| FTP_REMOTE_DIR | Путь к сайту относительно FTP-корня: public_html, либо / если пользователь ограничен непосредственно папкой public_html |

Сервер: vh460.timeweb.ru, порт 21. Перед первым запуском убедитесь, что пользователь видит index.html и _next в выбранной папке. Не используйте / если это корень всего аккаунта.

Соединение использует FTPS с проверкой сертификата; при отсутствии TLS загрузка завершится ошибкой, без перехода на открытый FTP. FTP-доступ и путь пока не проверены на реальном сервере.

Существующие файлы, .htaccess и старые _next-ресурсы не удаляются. Новые ресурсы передаются до HTML; каждый файл публикуется переименованием временного файла. Весь сайт целиком не переключается атомарно. Удалённые из проекта страницы сохранятся на сервере до отдельной очистки.

Для отката выполните revert проблемного коммита в main: следующий деплой загрузит предыдущую версию. Не запускайте очистку public_html перед деплоем.
