# Исламская хронология

Next.js (App Router), React, TypeScript. Статичные данные, без бэкенда.

## Запуск

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

## Проверка и production

```bash
npm run typecheck
npm run build
npm start
```

## Структура

- `src/app/` — страница, метаданные, глобальные стили.
- `src/components/chronology/` — дата, карточка личности, период.
- `src/data/chronology.ts` — личности и исторические периоды.
- `src/types/chronology.ts` — типы данных.

Даты по хиджре выделены жирным, григорианские показаны ниже. Периоды сворачиваются нативным details. Одна личность может входить в несколько периодов.

Даты демонстрационные, приблизительные даты отмечены «ок.». Перед публикацией необходима сверка с историческими источниками. Порядок карточек задаётся вручную и не является сортировкой по датам рождения.

Архив содержит исходники без node_modules и .next. Установка зависимостей требует доступа к npm. Сборку в среде создания архива не запускали.
